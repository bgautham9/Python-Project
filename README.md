# Python-Project
ASOS Fashion Data Analytics Project
Project Overview

This project focuses on analyzing a real-world ecommerce fashion dataset using Python.
The goal is to perform data cleaning, exploratory data analysis (EDA), and generate business insights from product-level fashion data.

The dataset contains information about:

Product names
Categories
Prices
Colors
Descriptions
Product images
SKU details

This project is part of my hands-on learning journey in Data Analytics and Python.

Objectives
Understand and clean raw ecommerce data
Perform exploratory data analysis (EDA)
Analyze pricing trends and product categories
Identify missing values and duplicates
Generate business insights using visualizations
Build a foundation for future recommendation systems
Tech Stack
Python

Jupyter Notebook
